# ElectroCompare

A revenue-ready starter website for comparing electronics.

## Run it
Open `index.html` in a browser.

## Before launch
1. Register for affiliate programs you are eligible for (for example, retailer affiliate networks).
2. Replace sample products/prices with licensed/current product feeds or APIs.
3. Add your affiliate tracking IDs to retailer URLs.
4. Connect the price-alert form to an email service/database.
5. Add privacy policy, terms, affiliate disclosure, and cookie/consent handling as appropriate.
6. Deploy to a host such as Netlify, Vercel, Cloudflare Pages, or your own server.

## Important
The sample prices/specifications in this demo are illustrative and are not live retailer data.
